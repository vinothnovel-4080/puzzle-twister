# Presenter portraits: image prompts

Six original presenters for Puzzle Twister explainer videos: 3 Indian and 3 Western women, about 25.
Generate each one **once** with any AI image tool (Gemini, Ideogram, Midjourney, ChatGPT and so on),
then save it in `presenters/faces/` with the file name shown. These portraits get animated
with lip-sync later, so they follow the same framing rules.

## Rules for every portrait (already included in each prompt)
- Head and shoulders, face centred, looking straight into the camera
- Mouth **closed** with a relaxed, slight smile; eyes open
- No hands, hair, glasses or jewellery covering the face
- Soft, even studio light; plain, softly blurred background
- Vertical 4:5 (or square), at least 1024 px wide
- Not resembling any real or famous person

**Negative prompt** (if the tool has one): `open mouth, teeth, hands, glasses, sunglasses, hat, hair over face,
side view, tilted head, heavy makeup, text, watermark, logo, extra fingers, blurry, cartoon, illustration, celebrity`

## After generating
1. Check each portrait: face straight on, mouth closed, nothing covering the face, no odd hands or ears.
2. Save them as `presenters/faces/indian_1.png` … `western_3.png`.
3. Note which tool made each one: its terms decide whether the images may be used commercially.
4. When posting, mark these videos with Instagram's **AI info** label (realistic AI people).
