# Character sheet prompts

Use the **same image tool and style line for every image** so the character stays consistent.
Generate one image per row below; save as `sensei/characters/<character>_<pose>.png`.
If the tool supports a reference image, give it the first good image of the character for the rest.

**Style line (add to every prompt):**
`original anime-style character, clean cel shading, bold outlines, vibrant colours, half-body shot,
facing the viewer, plain solid light-grey background, high resolution, no text, no watermark`

**Negative prompt:** `existing anime character, Gojo, Jujutsu Kaisen, logo, text, watermark, extra fingers,
blurry, realistic photo, busy background`
